# Material complementario del Classroom

Selección curada de materiales de la carpeta compartida del curso. Los nombres y la organización se normalizaron para facilitar la navegación desde GitHub.

## Cuadernos incorporados

- `00_repaso/`: repaso computacional de álgebra lineal.
- `01_aritmetica/`: ejemplo de precisión múltiple y mixta.
- `ortogonalizacion/pluto/`: versión del tema de ortogonalización preparada para Pluto.jl.
- `ortogonalizacion/colab/`: secuencia de Gram-Schmidt, Householder, Givens, Fast Givens y Householder por bloques.
- `04_valores_propios/`: Jacobi, iteración de potencias, cociente de Rayleigh, algoritmo QR y forma real de Schur.
- `06_metodos_iterativos/`: métodos de proyección, GMRES y gradiente conjugado.
- `tareas/`: enunciados de las tres tareas computacionales, convertidos a Markdown para lectura directa en GitHub.
